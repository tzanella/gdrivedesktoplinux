Gerenciadores de arquivos

O app conversa com o seu gerenciador de arquivos por D-Bus: o serviço do Drive publica ações que o Dolphin (plugin) e os gerenciadores GTK (extensão) mostram no menu do botão direito.

O plugin do Dolphin no .tar.gz

Ele vem pronto nos pacotes .deb, .rpm e Arch. No .tar.gz não: o Qt só procura plugins nas pastas do sistema. Compile com integrations/dolphin/build.sh (precisa de CMake e KF6).

O que aparece no menu

Dentro da pasta do Drive (Meu Drive ou Drives compartilhados), o botão direito num arquivo ou pasta mostra o submenu Google Drive:
AçãoO que faz
Abrir no navegadorAbre o item na web do Google Drive.
CompartilharAbre a janela Compartilhar: pessoas, papéis, acesso geral e link.
Copiar linkCopia o link e avisa quem pode abrir (só você, invited ou anyone).
Gerenciar versõesAbre a janela de versões: baixar, restaurar ou manter para sempre.
Adicionar atalho ao DriveEscolhe a pasta onde o atalho será criado (Meu Drive ou um Drive compartilhado).
Disponível off-line / Somente on-lineMarca conforme o estado atual do item.
Novo Documento / Planilha / ApresentaçãoCria o documento do Google na mesma pasta.
AtualizarReindexa a pasta.
Ver a lixeiraAbre a .Lixeira do Drive.
Nos arquivos do Office, o menu também oferece abrir no Documentos, Planilhas ou Apresentações. Fora da pasta do Drive, o submenu não aparece. No Dolphin, porém, uma pasta fora do Drive ganha a opção Sincronizar esta pasta com o Google Drive (veja a seção de backup).

Emblemas de estado (Dolphin)

No Dolphin, cada arquivo do Drive mostra um emblema:
EmblemaSignificado
Na nuvemO arquivo está na nuvem; abrir baixa só o que for lido.
Off-lineMarcado como disponível off-line.
SincronizandoEnvio ou download em andamento.
Em conflitoHá uma versão divergente no Lost and Found.
ErroO envio ou o download falhou (o “!” some quando o envio dá certo).

Miniaturas

As imagens aparecem com miniatura no Dolphin e em outros gerenciadores, usando as miniaturas do próprio Google — o arquivo em si não é baixado só para mostrar a imagem. As miniaturas ficam no cache padrão do freedesktop (`~/.cache/thumbnails`).

Exclusão do indexador do KDE

No KDE, o app tira a pasta do Drive do indexador de arquivos (Baloo), que baixaria tudo para ler o conteúdo dos arquivos e deixaria o computador lento. As outras pastas excluídas continuam como estavam. Desinstalar o app desfaz a mudança.

Reiniciar o gerenciador

Depois de instalar o pacote do gerenciador (ou o plugin do Dolphin), reinicie o gerenciador para a extensão ser carregada:
nautilus -q # Nautilus nemo -q # Nemo thunar -q # Thunar caja -q # Caja killall dolphin # Dolphin

Dica de uso

No menu do botão direito do Dolphin, use o emblema de estado para saber se o arquivo está na nuvem antes de abrir um vídeo grande: ele só baixa o trecho que você assiste.

Integration

File managers

The app talks to your file manager over D-Bus: the Drive service publishes actions that Dolphin (a plugin) and the GTK file managers (an extension) show in the right-click menu.

The Dolphin plugin in the .tar.gz

It comes ready-made in the .deb, .rpm and Arch packages. It does not in the .tar.gz: Qt only looks for plugins in system folders. Build it with integrations/dolphin/build.sh (needs CMake and KF6).

What shows up in the menu

Inside the Drive folder (My Drive or shared drives), right-clicking a file or folder shows the Google Drive submenu:
ActionWhat it does
Open in the browserOpens the item on the Google Drive website.
ShareOpens the Share window: people, roles, general access and link.
Copy linkCopies the link and warns who can open it (only you, invited or anyone).
Manage versionsOpens the versions window: download, restore or keep forever.
Add shortcut to DrivePicks the folder where the shortcut is created (My Drive or a shared drive).
Available offline / Online onlyMarks according to the current state of the item.
New Document / Sheet / SlidesCreates the Google document in the same folder.
RefreshRe-indexes the folder.
Show the trashOpens .Drive Trash.
On Office files, the menu also offers to open them in Docs, Sheets or Slides. Outside the Drive folder the submenu does not show up. In Dolphin, though, a folder outside the Drive gains the Sync this folder with Google Drive option (see the backup section).

Status badges (Dolphin)

In Dolphin, every Drive file shows a badge:
BadgeMeaning
In the cloudThe file is in the cloud; opening it downloads only what is read.
OfflineMarked as available offline.
SyncingAn upload or download is in progress.
In conflictThere is a diverging version in Lost and Found.
ErrorThe upload or download failed (the “!” disappears once the upload succeeds).

Thumbnails

Images show a thumbnail in Dolphin and other file managers, using Google's own thumbnails — the file itself is not downloaded just to show the picture. Thumbnails live in the standard freedesktop cache (`~/.cache/thumbnails`).

Excluding the KDE indexer

On KDE, the app takes the Drive folder out of the file indexer (Baloo), which would download everything just to read the file contents and slow your computer down. The other excluded folders stay as they were. Uninstalling the app undoes the change.

Restarting the file manager

After installing the file manager package (or the Dolphin plugin), restart the file manager so the extension gets loaded:
nautilus -q # Nautilus nemo -q # Nemo thunar -q # Thunar caja -q # Caja killall dolphin # Dolphin

Known limitations

LimitationWhy
There is no “Add to mirror” in the Dolphin menuOn Linux the Mirror is always the whole My Drive, not chosen folders.
There is no “Ask Gemini” in the Dolphin menuThere is no public address to open a file in Gemini; the card in the main window links to the Gemini page.
Network folders (NAS) cannot be syncedThe app refuses network and FUSE volumes.
On COSMIC Files the actions come looseCOSMIC Files does not take extensions or submenus.
Moving an item into a shared drive asks afterwardsA mounted folder cannot ask in the middle of a mv.

Tip

In the Dolphin right-click menu, use the status badge to know whether a file is in the cloud before opening a big video: it only downloads the part you watch.
