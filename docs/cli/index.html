Automação

CLI e servidor MCP

O app instala um programa de linha de comando, `gdrive-desktop-linux`, que conversa com o mesmo serviço do app por D-Bus. Tudo o que a janela faz, a CLI faz — inclusive em scripts.
gdrive-desktop-linux --help

Todos os comandos

ComandoO que faz
loginConecta uma conta Google, abrindo o navegador para autorizar.
status [--account <e-mail>]Mostra a conta, a pasta e o estado da sincronização (envios pendentes).
pin <caminho>Deixa um arquivo ou pasta disponível off-line.
unpin <caminho>Volta a deixar só on-line (libera o espaço).
pausePausa a sincronização.
resumeRetoma a sincronização.
sync [--account <e-mail>] [--folder <id>]Força a sincronização imediata de tudo ou de uma pasta específica.
lost-and-found [--account <e-mail>]Lista as edições guardadas por conflito.
logout [--account <e-mail>] [--all]Sai de uma conta ou de todas, decidindo o que fazer com os envios pendentes.
open-pointer <arquivo>Abre um .gdoc, .gsheet… no navegador (é o que o duplo clique faz).
menu-action <ação> <caminho>…Executa uma ação do menu do botão direito (usado pelo COSMIC Files).
uninstall [--purge] [--yes]Desinstala o app; --purge apaga também os dados deste computador.

Exemplos

Entrar e ver o estado

gdrive-desktop-linux login gdrive-desktop-linux status
Para entrar sem passar pela interface, com o segredo em arquivo (fora do histórico do shell):
gdrive-desktop-linux login \ --client-id SEU_CLIENT_ID \ --client-secret-file ~/.config/gdrive/client-secret.txt

Deixar um arquivo disponível off-line

gdrive-desktop-linux pin "~/Google Drive/Meu Drive/Relatórios" gdrive-desktop-linux unpin "~/Google Drive/Meu Drive/Filmes"

Controlar a sincronização num script

# pausa enquanto a reunião acontece gdrive-desktop-linux pause sleep 3600 gdrive-desktop-linux resume

Sair da conta com envios pendentes

Há três saídas possíveis, e elas se combinam:
# espera os envios pendentes terminarem e sai gdrive-desktop-linux logout --finish # copia os arquivos com envio pendente para uma pasta antes de sair gdrive-desktop-linux logout --move ~/Documentos/pendentes # descarta os envios pendentes gdrive-desktop-linux logout --discard # sai de todas as contas gdrive-desktop-linux logout --all
⚠️
O Lost and Found nunca é apagado

Mesmo com --discard, as versões guardadas por conflito ficam.

Forçar uma sincronização

gdrive-desktop-linux sync gdrive-desktop-linux sync --folder 1A2b3C4D5E6F
O --folder recebe o ID numérico da pasta (o mesmo que aparece no link do Drive).

Servidor MCP

O programa `gdrive-desktop-linux-mcp` deixa um assistente de IA compatível com o Model Context Protocol (Claude Desktop, Claude Code e outros) consultar e organizar o Drive pelo serviço do app, sem credencial própria. O que o assistente pode fazer:
AçãoDescrição
Estado de um caminhoSe aquele caminho está sincronizado, offline ou com erro.
Link da webO endereço do item no Google Drive.
Pastas acompanhadasQuais pastas do computador estão sincronizadas.
CompartilharAbre a janela Compartilhar com o e-mail já digitado — nada é compartilhado sem você confirmar.
Adicionar pastaAdiciona uma pasta à sincronização: backup (cópia em “Computadores”, a pasta fica onde está) ou stream (a pasta vai para o Meu Drive e um link fica no lugar; a original vai para a lixeira do sistema).
O servidor só aceita pastas visíveis dentro da sua pasta pessoal.

Registrar no Claude Code

claude mcp add google-drive -- gdrive-desktop-linux-mcp

Registrar em outro cliente MCP

```json { "mcpServers": { "google-drive": { "command": "gdrive-desktop-linux-mcp" } } } ```

Limitações conhecidas

SituaçãoComportamento
Vim e Neovim com backupcopy=autoSalvam renomeando o original e criando outro: o conteúdo não se perde, mas no Drive o arquivo ganha um ID novo e o antigo vai para a lixeira (links compartilhados do antigo deixam de valer). Com set backupcopy=yes o ID se mantém.
Pasta criada que ainda não subiu e vai para a lixeiraSome só deste computador.
Conta que ainda não terminou a primeira leitura do DriveFica fora da lista até a próxima partida, se não conseguir subir logo no começo.
Modo EspelhoOs Drives compartilhados continuam na pasta do Google Drive, em Stream.

Automation

CLI and MCP server

The app installs a command line program, `gdrive-desktop-linux`, which talks to the same service as the app over D-Bus. Everything the window does, the CLI does — including inside scripts.
gdrive-desktop-linux --help

All the commands

CommandWhat it does
loginConnects a Google account, opening the browser to authorize.
status [--account <e-mail>]Shows the account, the folder and the sync state (pending uploads).
pin <path>Makes a file or folder available offline.
unpin <path>Goes back to online only (frees the space).
pausePauses the synchronization.
resumeResumes the synchronization.
sync [--account <e-mail>] [--folder <id>]Forces an immediate sync of everything or of a specific folder.
lost-and-found [--account <e-mail>]Lists the edits kept from conflicts.
logout [--account <e-mail>] [--all]Signs out of one account or all of them, deciding what to do with pending uploads.
open-pointer <file>Opens a .gdoc, .gsheet… in the browser (what the double click does).
menu-action <action> <path>…Runs a right-click menu action (used by COSMIC Files).
uninstall [--purge] [--yes]Uninstalls the app; --purge also wipes the data on this computer.

Examples

Sign in and check the state

gdrive-desktop-linux login gdrive-desktop-linux status
To sign in without going through the UI, with the secret in a file (out of your shell history):
gdrive-desktop-linux login \ --client-id YOUR_CLIENT_ID \ --client-secret-file ~/.config/gdrive/client-secret.txt

Making a file available offline

gdrive-desktop-linux pin "~/Google Drive/My Drive/Reports" gdrive-desktop-linux unpin "~/Google Drive/My Drive/Movies"

Controlling the sync from a script

# pause while the meeting happens gdrive-desktop-linux pause sleep 3600 gdrive-desktop-linux resume

Signing out with pending uploads

There are three possible ways out, and they combine:
# wait for the pending uploads to finish and sign out gdrive-desktop-linux logout --finish # copy the files with pending upload to a folder before signing out gdrive-desktop-linux logout --move ~/Documents/pending # discard the pending uploads gdrive-desktop-linux logout --discard # sign out of all the accounts gdrive-desktop-linux logout --all
⚠️
Lost and Found is never deleted

Even with --discard, the versions kept from conflicts stay.

Forcing a sync

gdrive-desktop-linux sync gdrive-desktop-linux sync --folder 1A2b3C4D5E6F
The --folder takes the numeric folder ID (the same one you see in the Drive link).

MCP server

The `gdrive-desktop-linux-mcp` program lets an AI assistant compatible with the Model Context Protocol (Claude Desktop, Claude Code and others) query and organize the Drive through the app service, with no credentials of its own. What the assistant can do:
ActionDescription
Status of a pathWhether that path is synced, offline or in error.
Web linkThe address of the item on Google Drive.
Watched foldersWhich computer folders are being synced.
ShareOpens the Share window with the e-mail already typed — nothing is shared without your confirmation.
Add a folderAdds a folder to the sync: backup (copy into “Computers”, the folder stays where it is) or stream (the folder goes to My Drive and a link is left in its place; the original goes to the system trash).
The server only accepts folders visible inside your personal folder.

Registering it in Claude Code

claude mcp add google-drive -- gdrive-desktop-linux-mcp

Registering it in another MCP client

```json { "mcpServers": { "google-drive": { "command": "gdrive-desktop-linux-mcp" } } } ```

Known limitations

SituationBehavior
Vim and Neovim with backupcopy=autoThey save by renaming the original and creating another: no content is lost, but on the Drive the file gets a new ID and the old one goes to the trash (shared links of the old file stop working). With set backupcopy=yes the ID is kept.
A folder created that has not uploaded yet and is trashedIt disappears only from this computer.
An account that has not finished its first read of the DriveIt stays out of the list until the next start, if it cannot upload right away.
Mirror modeShared drives stay in the Google Drive folder, in Stream.
