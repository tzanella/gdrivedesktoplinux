Instalação

Guia de instalação

O GDrive Desktop é distribuído como pacotes para as distribuições mais comuns e também como um `.tar.gz` que instala sem root. Esta página vai do download ao primeiro uso.
📋
Pré-requisitos
  • Linux de 64 bits (x86_64).
  • FUSE 3 e WebKitGTK 4.1 — já vêm no quase todas as distribuições gráficas.
  • Uma conta Google e um Client ID próprio: veja o guia do Client ID.

1. Baixar o pacote

Vá até a página de releases e escolha o arquivo da sua distribuição:
DistribuiçãoArquivoComo instalar
Ubuntu 22.04+, Debian 12+, Mint, Pop!_OS.debsudo apt install ./gdrive-desktop-linux_*.deb
Fedora, Nobara, openSUSE.rpmsudo dnf install ./gdrive-desktop-linux-*.rpm
openSUSE: sudo zypper install --allow-unsigned-rpm ./…rpm
Arch, Manjaro, EndeavourOS, CachyOS.pkg.tar.zstsudo pacman -U ./gdrive-desktop-linux-*.pkg.tar.zst
Qualquer outra.tar.gztar -xzf … e depois ./install.sh (sem root, vai para ~/.local)

Conferir a integridade dos arquivos

Todo release vem com um arquivo SHA256SUMS. Na mesma pasta do pacote, rode:
sha256sum -c --ignore-missing SHA256SUMS
O resultado esperado é OK para cada arquivo conferido. Se aparecer FALHOU, o download não foi concluído ou o arquivo foi alterado: baixe de novo.
⚠️
Baixe sempre do repositório oficial

Este projeto não tem vínculo com o Google. Pacotes com o mesmo nome em outros sites não são necessariamente este app.

2. Instalar

Ubuntu, Debian, Mint e Pop!_OS

sudo apt install ./gdrive-desktop-linux_*.deb
O `apt` resolve as dependências (FUSE 3 e WebKitGTK 4.1) automaticamente.

Fedora, Nobara e openSUSE

sudo dnf install ./gdrive-desktop-linux-*.rpm
No openSUSE, o pacote não é assinado pelo repositório:
sudo zypper install --allow-unsigned-rpm ./gdrive-desktop-linux-*.rpm

Arch, Manjaro, EndeavourOS e CachyOS

sudo pacman -U ./gdrive-desktop-linux-*.pkg.tar.zst

Qualquer outra distribuição (ou sem root)

O `.tar.gz` instala no seu usuário, em `~/.local`, sem pedir senha de administrador:
tar -xzf gdrive-desktop-linux-*.tar.gz cd gdrive-desktop-linux-*/ ./install.sh
Antes disso, instale o FUSE 3 e o WebKitGTK 4.1 da sua distribuição. O script `install.sh` também aceita `--prefix` para instalar em outro lugar.

3. Dependências do gerenciador de arquivos

Os pacotes `.deb`, `.rpm` e Arch já trazem o plugin do Dolphin e a extensão para os gerenciadores GTK. No `.tar.gz`, o plugin do Dolphin não vem (o Qt só procura plugins nas pastas do sistema) e as extensões GTK precisam do pacote de Python do gerenciador:
GerenciadorPacote necessário
Nautilus (GNOME, Ubuntu, Pop!_OS 22.04, Zorin)nautilus-python ou python3-nautilus
Nemo (Cinnamon, Mint)python3-nemo
Caja (MATE)python3-caja ou python-caja
Thunar (Xfce)thunarx-python
Exemplo no Debian/Ubuntu:
sudo apt install nautilus-python thunarx-python
Depois de instalar o pacote do gerenciador, reinicie o gerenciador para a extensão ser carregada.

4. Compilar a partir do código

Precisa de Rust 1.99 ou mais novo, FUSE 3 e as bibliotecas da janela.
DistribuiçãoDependências
Fedora / Nobarasudo dnf install fuse3 webkit2gtk4.1-devel libsoup3-devel librsvg2-devel dbus-devel
Debian / Ubuntusudo apt install fuse3 libwebkit2gtk-4.1-dev librsvg2-dev libdbus-1-dev build-essential
O script compila em modo release e instala para o seu usuário, sem root:
git clone https://github.com/tzanella/gdrivedesktoplinux.git cd gdrive-desktop-linux scripts/install-dev.sh
Opções úteis:
scripts/install-dev.sh --dry-run # só mostra o que instalaria scripts/install-dev.sh --prefix /outro/lugar
O script instala os quatro programas (serviço, CLI, bandeja e janela), o serviço do usuário (systemd), a ativação do serviço e da janela pelo D-Bus, o atalho no menu de aplicativos, a abertura dos ponteiros `.gdoc`, os ícones e a extensão do menu do botão direito para Nautilus, Nemo, Caja e Thunar. Os plugins do Dolphin (menu e emblemas de estado) compilam à parte:
integrations/dolphin/build.sh
Eles precisam de CMake e KF6 e vão para a pasta de plugins do Qt do sistema.

5. Primeiro uso

1. Procure Google Drive no menu de aplicativos (ou rode gdrive-desktop-linux-tray). 2. A bandeja liga o serviço e, sem conta, abre o primeiro uso, que guia a criação do seu Client ID parte por parte, com botões que abrem cada página do Google Cloud e copiam os valores. 3. Cole o Client ID e o segredo e entre pelo navegador. Veja o guia do Client ID para o passo a passo detalhado. 4. A pasta aparece em ~/Google Drive/Meu Drive. Outras contas entram pelo menu da conta (Adicionar outra conta) e ganham a própria pasta, ~/Google Drive (<e-mail>).

6. Desinstalar

Pelo item Desinstalar Google Drive do menu de aplicativos, ou pelo botão Desinstalar… em Mais opções › Sobre. A janela pergunta se apaga também os dados deste computador (conta conectada, cache, arquivos off-line, miniaturas e preferências). As cópias do Lost and Found ficam. Pelo terminal:
sudo apt remove gdrive-desktop-linux # ou dnf remove / pacman -R
Só os programas saem e os dados ficam, como é o padrão no Linux. Para apagar tudo:
gdrive-desktop-linux uninstall --purge
> Desconecte a conta antes de usar `--purge`. Quem instalou pelo `.tar.gz` também pode rodar ./uninstall.sh na pasta descompactada.

Problemas na instalação

SintomaO que fazer
fusermount3: mount failed: Operation not permittedO FUSE 3 não está instalado ou o usuário não está no grupo fuse. Recarregue a sessão (saia e entre de novo) depois de instalar o pacote.
A janela não abre, mas a bandeja apareceFalta o WebKitGTK 4.1. No Debian/Ubuntu: sudo apt install libwebkit2gtk-4.1-dev (no pacote final, a biblioteca em tempo de execução).
O menu do botão direito não aparece no Nautilus/Nemo/Caja/ThunarFalta o pacote de Python do gerenciador. Veja a página de gerenciadores.
O ícone não aparece no painel do DolphinO plugin do Dolphin não veio no .tar.gz ou o Qt não procura plugins nessa pasta. Compile com integrations/dolphin/build.sh.
apt install ./arquivo.deb falha com “Não foi possível obter o ficheiro”O pacote não está no diretório atual. Use o caminho completo: sudo apt install ./~/Downloads/gdrive-desktop-linux_1.2.5_amd64.deb.
O serviço não sobeVeja journalctl --user -u gdrive-desktop-linuxd e a página de solução de problemas.

Installation

Installation guide

GDrive Desktop ships as packages for the most common distributions and also as a `.tar.gz` that installs without root. This page goes from download to first use.
📋
Requirements
  • 64-bit Linux (x86_64).
  • FUSE 3 and WebKitGTK 4.1 — already present in most graphical distributions.
  • A Google account and your own Client ID: see the Client ID guide.

1. Download the package

Go to the releases page and pick the file for your distribution:
DistributionFileHow to install
Ubuntu 22.04+, Debian 12+, Mint, Pop!_OS.debsudo apt install ./gdrive-desktop-linux_*.deb
Fedora, Nobara, openSUSE.rpmsudo dnf install ./gdrive-desktop-linux-*.rpm
openSUSE: sudo zypper install --allow-unsigned-rpm ./…rpm
Arch, Manjaro, EndeavourOS, CachyOS.pkg.tar.zstsudo pacman -U ./gdrive-desktop-linux-*.pkg.tar.zst
Anything else.tar.gztar -xzf … then ./install.sh (no root, lands in ~/.local)

Verify the downloaded files

Every release ships a SHA256SUMS file. In the same folder as the package, run:
sha256sum -c --ignore-missing SHA256SUMS
The expected output is OK for every checked file. If you see FAILED, the download did not finish or the file was tampered with: download it again.
⚠️
Always download from the official repository

This project is not affiliated with Google. Packages with the same name on other sites are not necessarily this app.

2. Install

Ubuntu, Debian, Mint and Pop!_OS

sudo apt install ./gdrive-desktop-linux_*.deb
`apt` resolves the dependencies (FUSE 3 and WebKitGTK 4.1) automatically.

Fedora, Nobara and openSUSE

sudo dnf install ./gdrive-desktop-linux-*.rpm
On openSUSE the package is not signed by the repository:
sudo zypper install --allow-unsigned-rpm ./gdrive-desktop-linux-*.rpm

Arch, Manjaro, EndeavourOS and CachyOS

sudo pacman -U ./gdrive-desktop-linux-*.pkg.tar.zst

Any other distribution (or without root)

The `.tar.gz` installs into your user directory, in `~/.local`, without asking for an admin password:
tar -xzf gdrive-desktop-linux-*.tar.gz cd gdrive-desktop-linux-*/ ./install.sh
Install FUSE 3 and WebKitGTK 4.1 from your distribution first. The `install.sh` script also accepts `--prefix` to install somewhere else.

3. File manager dependencies

The `.deb`, `.rpm` and Arch packages already include the Dolphin plugin and the extension for the GTK file managers. In the `.tar.gz`, the Dolphin plugin is not included (Qt only looks for plugins in system folders) and the GTK extensions need the file manager's Python package:
File managerRequired package
Nautilus (GNOME, Ubuntu, Pop!_OS 22.04, Zorin)nautilus-python or python3-nautilus
Nemo (Cinnamon, Mint)python3-nemo
Caja (MATE)python3-caja or python-caja
Thunar (Xfce)thunarx-python
Example on Debian/Ubuntu:
sudo apt install nautilus-python thunarx-python
After installing the file manager package, restart the file manager so the extension is loaded.

4. Build it from source

You need Rust 1.99 or newer, FUSE 3 and the window libraries.
DistributionDependencies
Fedora / Nobarasudo dnf install fuse3 webkit2gtk4.1-devel libsoup3-devel librsvg2-devel dbus-devel
Debian / Ubuntusudo apt install fuse3 libwebkit2gtk-4.1-dev librsvg2-dev libdbus-1-dev build-essential
The script compiles in release mode and installs for your user, without root:
git clone https://github.com/tzanella/gdrivedesktoplinux.git cd gdrive-desktop-linux scripts/install-dev.sh
Useful options:
scripts/install-dev.sh --dry-run # only shows what it would install scripts/install-dev.sh --prefix /some/other/place
The script installs the four programs (service, CLI, tray and window), the user service (systemd), the D-Bus activation of the service and the window, the applications menu shortcut, the opening of `.gdoc` pointers, the icons and the right-click menu extension for Nautilus, Nemo, Caja and Thunar. The Dolphin plugins (menu and status badges) are built separately:
integrations/dolphin/build.sh
They need CMake and KF6 and go into the system Qt plugins folder.

5. First run

1. Look for Google Drive in your applications menu (or run gdrive-desktop-linux-tray). 2. The tray starts the service and, with no account connected, opens the first run, which walks you through creating your Client ID, with buttons that open each Google Cloud page and copy the values. 3. Paste the Client ID and the client secret and sign in through the browser. See the Client ID guide for the detailed walkthrough. 4. The folder shows up at ~/Google Drive/My Drive. Other accounts come in through the account menu (Add another account) and get their own folder, ~/Google Drive (<e-mail>).

6. Uninstall

From the Uninstall Google Drive item in your applications menu, or the Uninstall… button in More options › About. The window asks whether to also wipe the data on this computer (connected account, cache, offline files, thumbnails and preferences). Lost and Found copies are kept. From the terminal:
sudo apt remove gdrive-desktop-linux # or dnf remove / pacman -R
Only the programs are removed and the data stays, which is the Linux default. To wipe everything:
gdrive-desktop-linux uninstall --purge
> Disconnect the account before using `--purge`. If you installed the `.tar.gz`, you can also run ./uninstall.sh in the extracted folder.

Installation problems

SymptomWhat to do
fusermount3: mount failed: Operation not permittedFUSE 3 is not installed or your user is not in the fuse group. Reload the session (log out and back in) after installing the package.
The window never opens but the tray shows upWebKitGTK 4.1 is missing. On Debian/Ubuntu: sudo apt install libwebkit2gtk-4.1-dev (the runtime library, for the packaged build).
No right-click menu in Nautilus/Nemo/Caja/ThunarThe file manager's Python package is missing. See the file managers page.
The icon does not show in the Dolphin panelThe Dolphin plugin is not in the .tar.gz, or Qt does not look for plugins in that folder. Build it with integrations/dolphin/build.sh.
apt install ./file.deb fails with “Could not get file”The package is not in the current directory. Use the full path: sudo apt install ./~/Downloads/gdrive-desktop-linux_1.2.5_amd64.deb.
The service does not startCheck journalctl --user -u gdrive-desktop-linuxd and the troubleshooting page.
