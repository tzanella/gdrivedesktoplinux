GDrive Desktop

GDrive Desktop é um cliente não oficial do Google Drive para Linux, escrito em Rust, com o mesmo comportamento, aparência e funcionalidades do Google Drive para computador (versão Windows). O app não tem servidores próprios: ele roda inteiro na sua máquina e conversa com a API pública do Google usando um Client ID que você mesmo cria no seu projeto do Google Cloud. Os seus arquivos nunca passam por um servidor do projeto.

O que o app faz

O Drive aparece como uma pasta comum no seu gerenciador de arquivos, mas os arquivos ficam na nuvem até você abrir: só os trechos lidos são baixados. Em cima disso, o app entrega: - Sincronização automática de envio e recebimento, com fila que sobrevive a reinícios e queda de rede. - “Disponível off-line” em arquivos e pastas, e “Somente on-line” para liberar o espaço na hora. - Menu do botão direito nos gerenciadores de arquivos, com compartilhar, versões, atalhos e lixeira. - Até 4 contas Google ao mesmo tempo, cada uma com a sua pasta. - Drives compartilhados, visíveis na pasta e numa visão própria da janela principal. - Modo Espelho: o Meu Drive inteiro numa pasta comum do computador, disponível sem internet. - Pastas do computador sincronizadas e backup de pendrives quando conectados. - Proteção: detecta arquivos que parecem cifrados por um vírus e pausa os envios antes de estragar tudo. - Recuperação: dados locais danificados são refeitos a partir do Drive, com as edições pendentes guardadas. - Diagnóstico e feedback sem tokens, senhas ou e-mails nos relatórios. A lista completa está em Recursos do app.

Como funciona

CamadaO que faz
Interface (Tauri)Bandeja, login, preferências e a janela principal com a atividade de sincronização.
Gerenciadores de arquivosPlugin do Dolphin e extensão GTK com o menu do botão direito e os emblemas de estado.
Motor (serviço em Rust)Pasta virtual via FUSE, banco SQLite com os metadados de todo o Drive, cache em blocos, fila de envios e resolução de conflitos.
Google Drive APIHTTPS + OAuth 2.0, usando apenas a API pública.
A interface e os gerenciadores conversam com o motor por D-Bus; o motor fala com o Google por HTTPS.

GDrive Desktop

GDrive Desktop is an unofficial Google Drive client for Linux, written in Rust, with the same behavior, look and features as Google Drive for desktop (the Windows version). The app has no servers of its own: it runs entirely on your machine and talks to the public Google API using a Client ID that you create yourself in your own Google Cloud project. Your files never pass through a project server.

What the app does

The Drive shows up as a regular folder in your file manager, but the files stay in the cloud until you open them: only the chunks you read are downloaded. On top of that, the app delivers: - Automatic sync of uploads and downloads, with a queue that survives restarts and network drops. - “Available offline” for files and folders, and “Online only” to free the space right away. - Right-click menu in file managers, with sharing, versions, shortcuts and trash. - Up to 4 Google accounts at once, each with its own folder. - Shared drives, visible in the folder and in a dedicated view of the main window. - Mirror mode: your whole My Drive as a regular folder on the computer, available offline. - Computer folders synced and backup of USB drives when they are plugged in. - Protection: it spots files that look virus-encrypted and pauses uploads before things get bad. - Recovery: damaged local data is rebuilt from the Drive, with pending edits kept safe. - Diagnostics and feedback with no tokens, passwords or e-mails in the reports. The full list is in App features.

How it works

LayerWhat it does
Interface (Tauri)Tray, login, preferences and the main window with the sync activity.
File managersDolphin plugin and GTK extension with the right-click menu and the status badges.
Engine (Rust service)Virtual folder via FUSE, SQLite database with the metadata of the whole Drive, block cache, upload queue and conflict resolution.
Google Drive APIHTTPS + OAuth 2.0, using only the public API.
The interface and the file managers talk to the engine over D-Bus; the engine talks to Google over HTTPS.

Key concepts

TermMeaning
StreamDefault mode. The Drive shows up as a virtual folder: files live in the cloud and are downloaded on demand.
MirrorYour whole My Drive becomes a regular folder on the computer, with every file available offline. The Exchange switches between the two.
Available offlineMarks a file or folder to stay on disk. “Online only” undoes it and frees the space.
Shared drivesAreas shared with your account. They stay in Stream even in Mirror mode, just like the official app.
ComputersThe Drive folder that holds copies of synced computer folders and device backups.
Lost and FoundHolds conflicting versions and edits that have not uploaded yet. Nothing is ever silently overwritten.

Where the app keeps things

PathContent
~/Google Drive/My DriveThe Drive mounted in Stream mode.
~/Google Drive/Shared drivesThe shared drives of the account.
~/Google Drive (<e-mail>)The folder of each additional account (from the second one on).

~/.config/gdrive-desktop-linuxYour user preferences (preferences.toml).
~/.local/state/gdrive-desktop-linuxState and crash reports.
/etc/gdrive-desktop-linuxSystem policies (policies.toml) and defaults (defaults.toml).
