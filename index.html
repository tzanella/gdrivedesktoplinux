Como funciona

Uma pasta na nuvem que se comporta como uma pasta de verdade

Uma pasta virtual via FUSE monta o Drive no sistema de arquivos. Você abre um arquivo e só o trecho lido é baixado — o resto continua na nuvem.

Instalação

Baixe o pacote da sua distribuição

Escolha o seu sistema. Todos os pacotes são de 64 bits (x86_64) e verificados com o SHA256SUMS do release.

Flatpak (Universal)

flatpak install ./gdrive-desktop-linux-*.flatpak

Ubuntu · Debian · Mint · Pop!_OS

sudo apt install ./gdrive-desktop-linux_*.deb

Fedora · Nobara · openSUSE

sudo dnf install ./gdrive-desktop-linux-*.rpm

Arch · Manjaro · EndeavourOS · CachyOS

sudo pacman -U ./gdrive-desktop-linux-*.pkg.tar.zst

Qualquer outra

tar -xzf gdrive-desktop-linux-*.tar.gz && ./gdrive-desktop-linux-*/install.sh

Ou compilar a partir do código

scripts/install-dev.sh

Conferir a integridade dos arquivos

sha256sum -c --ignore-missing SHA256SUMS

Linha de comando

Uma CLI para o que você quiser automatizar

O mesmo motor do app, direto no terminal — com um servidor MCP incluído para assistentes de IA.

gdrive-desktop-linux — terminal

$ gdrive-desktop-linux login

→ abre o navegador para autorizar a conta

$ gdrive-desktop-linux status

→ conta, pasta e envios pendentes

$ gdrive-desktop-linux pin ~/Documentos

→ deixa disponível off-line

$ gdrive-desktop-linux pause / resume

$ gdrive-desktop-linux lost-and-found

→ lista as edições guardadas por conflito

$ gdrive-desktop-linux uninstall --purge

$ gdrive-desktop-linux open-pointer arquivo.gdoc

Servidor MCP

claude mcp add google-drive -- gdrive-desktop-linux-mcp
